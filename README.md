# 🏨 Grand Royal Hotel – Management System

A Hotel Management System built with **Python** and **Object-Oriented Programming (OOP)**, featuring both Command-Line Interface (CLI) and Graphical User Interface (GUI) versions.

The project simulates essential hotel operations, including room management, reservations, guest check-in, and check-out.

## ✨ Features

* **Room Management:** Manage Single and Double rooms.
* **Reservations:** Book rooms and assign them to guests.
* **Room Availability:** Track available rooms.
* **Guest Records:** View active guests and booking information.
* **Check-in & Check-out:** Manage guest stays and room departures.
* **Billing:** Calculate booking costs based on room type and duration.

## 🖥️ Project Versions

### 1. CLI Version

A command-line application developed independently by me using Python and OOP.

This version was designed and implemented entirely by me, including the class structure, inheritance, room management, booking logic, and check-out functionality.

### 2. GUI Version

A graphical version of the system developed with AI assistance.

It provides a visual interface for interacting with the hotel's management features.
